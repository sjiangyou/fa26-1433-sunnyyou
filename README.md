# Research project title

What is the impact of strengthening hurricanes on home and flood insurance prices in hurricane and flood prone areas?

## Reproducing the project

The complete currently implemented workflow is:

```bash
make
```

This checks that Python and R are available, creates or updates the project-local
R `renv` environment with `here` and `ggplot2`, and downloads all configured raw
data. The first R setup requires internet access so that `renv` can install the
packages; the resolved versions are recorded in `renv.lock` after the first
successful setup. The lockfile is intentionally generated by `renv` so it
captures the versions available in the installation environment.

Individual stages are available through `make help`. In particular,
`make download-raw` downloads the configured raw-data sources, and `make all`
runs every configured download followed by the R derivation scripts. Data
manipulation and plotting will use R; model training and evaluation will use
Python as those stages are added.

The raw-data acquisition script uses FEMA's public OpenFEMA endpoints:

```bash
python code/download_fema_nfip_data.py
```

This downloads the FEMA disaster-declaration and current v3 redacted NFIP-claims
files into `data/raw/`, and skips the existing NFIP policy extract. The policy file
is approximately 30 GB, so the raw data are excluded from Git. See
[`data/raw/SOURCES.md`](data/raw/SOURCES.md) for source links, file contents,
and retrieval notes. The acquisition command must be run in an environment
with internet access.

## Repository structure

| Directory | Purpose |
|---|---|
| `code/` | Scripts used to acquire, clean, analyze, and visualize data |
| `data/raw/` | Original source data; ignored by Git unless explicitly allowed |
| `data/derived/` | Data created by the project's code; ignored by Git unless explicitly allowed |
| `output/` | Generated figures, tables, and other results |
| `paper/` | Paper source files and rendered drafts |

## Data status

The repository currently contains the redacted NFIP policy extract at
`data/raw/FimaNfipPoliciesV2.csv`. Disaster declarations and NFIP claims can
be retrieved with the acquisition script above. These sources cover NFIP
policies and claims, not private flood insurance, and the records are redacted
for analysis at geographic rather than named-household level.
